## ୨୧ Design Direction

The visual identity follows a minimal digital archive concept.

- Monochromatic black-and-white palette
- Muted purple accent colour
- Archivo Black, DM Sans, and DM Mono typography
- Rounded borders and subtle details
- Smooth transitions and hover states
- Responsive layouts

The goal was to create something that feels personal, expressive, and functional without overwhelming the content.

## ୨୧ Running Locally

You can run the portfolio locally by following these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/foulboness/portfolio-26-.git
   ```

2. Navigate into the project folder:

   ```bash
   cd portfolio-26-
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the Live Server extension.
